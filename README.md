BreaKHis Label-Free Clustering Analysis



This repository contains the analysis notebook and supporting figures used for the study of unsupervised clustering of breast histopathological images from the BreaKHis dataset.

Dataset



The BreaKHis images are not redistributed in this repository. The dataset should be obtained separately from the official BreaKHis source and used in accordance with its applicable terms.



Official dataset source:



UFPR Vision, Robotics and Image Processing Laboratory



https://web.inf.ufpr.br/vri/databases/breast-cancer-histopathological-database-breakhis/



The dataset should be downloaded separately and the appropriate local dataset path configured in the analysis notebook before execution.



Reproducibility



The notebook conferenceBreaKhis\_CLustering.ipynb contains the analysis workflow used to generate the results reported in the associated manuscript.



The deposited notebook represents the version of the analysis code used for the reported study. Any known implementation limitations relevant to interpretation or reproduction are documented in the repository and associated manuscript.



Software requirements



The analysis was developed using Python and Jupyter Notebook/Google Colab. Required Python packages and analysis procedures are contained within the notebook.
